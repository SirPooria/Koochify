# کوچیفای (Kochify) — سامانه هوشمند تصمیم‌یار مهاجرت ویژه ایرانیان

> **کوچیفای (Kochify)** یک پلتفرم متن‌باز، مدرن و جامع تصمیم‌یار مهاجرتی به زبان فارسی است که متقاضی ایرانی را از «ناآگاهی اولیه و سردرگمی میان تبلیغات غیرواقعی» به یک «برنامه مهاجرتی روشن، مستدل، شخصی‌سازی‌شده و قابل اقدام» می‌رساند.

این سامانه مطابق با ضوابط مانیفست منطق مهاجرتی (`kochify_migration_logic_fa.md`) طراحی شده است و بدون نیاز به کلیدهای API تجاری خارجی، با یک موتور تطبیق محلی قدرتمند، کاتالوگ ساخت‌یافته و داده‌های تفکیک‌شده کار می‌کند.

---

## ۱. ویژگی‌های کلیدی سامانه

### الف) شروع بدون پیش‌نیاز و هدایت هدفمند (مرحله صفر)
- انتخاب شفاف میان «تحصیل»، «کار»، «هر دو» یا «هنوز مطمئن نیستم».
- تکمیل اولیه تنها با بازه‌های تخمینی؛ **بدون نیاز به ثبت شماره پاسپورت، کد ملی، شماره حساب یا مدارک هویتی محرمانه**.
- مسیرهای «نمی‌دانم» با راهنمایی‌های ملموس که مانع بن‌بست در ارزیابی می‌شوند.

### ب) فرم ارزیابی هوشمند و شرطی ۷ مرحله‌ای (مرحله یک)
- **مرحله ۱:** اهداف مهاجرت، افق زمانی و ترجیحات کشورها.
- **مرحله ۲:** مشخصات پایه، وضعیت نظام وظیفه، تأهل و الحاق همراهان.
- **مرحله ۳:** سوابق تحصیلی، دانشگاه، معدل، مقیاس و وضعیت پایان‌نامه.
- **مرحله ۴:** سوابق شغلی، عنوان استاندارد، وظایف واقعی، ابزارها و مجوزهای حرفه‌ای.
- **مرحله ۵:** سنجش مهارتی زبان انگلیسی (چهار مهارت تفکیک‌شده) و زبان دوم.
- **مرحله ۶:** توان مالی، بازه بودجه سال اول و منابع تأمین وجه (پس‌انداز/اسپانسر/وام).
- **مرحله ۷:** اولویت‌های سبک زندگی (هزینه، آب‌وهوا، نزدیکی به جامعه ایرانی، اقامت بلندمدت).
- ذخیره‌سازی خودکار در حافظه مرورگر (`localStorage`) جهت جلوگیری از دست رفتن اطلاعات.

### پ) موتور تطبیق و رتبه‌بندی ۳ مقصد متمایز (بدون شانس‌فروشی)
- **تفکیک مسیرها:** تحصیلی، کاری کارفرمایی، مهارتی امتیازی، جست‌وجوی کار و پژوهشی/دکترا.
- **پالایش شروط اجباری (Hard Gates):** بررسی دقیق سقف سن، مدارک پایه، زبان و تمکن. هرگز شرط ردکننده با امتیاز بالا خنثی نمی‌شود و وضعیت «فعلاً واجد شرایط نیست» با دلیل مستند صادر می‌گردد.
- **فرمول ۷ بُعدی امتیاز تناسب (Fit Score تا ۱۰۰):**
  1. واقع‌بینی و تناسب مسیر (وزن ۲۵)
  2. تناسب رشته تحصیلی یا عنوان شغلی (وزن ۲۰)
  3. سطح زبان واقعی در برابر الزام قانونی (وزن ۱۵)
  4. استطاعت و توانمندی مالی (وزن ۱۵)
  5. کیفیت سابقه کار و اعتبار مدرک (وزن ۱۰)
  6. تطابق با ترجیحات سبک زندگی (وزن ۱۰)
  7. آمادگی اداری و زمان‌بندی (وزن ۵)
- خروجی منحصراً شامل **حداکثر ۳ کشور متمایز** با بهترین مسیر حقوقی همان کشور است.
- امتیازها صراحتاً با عنوان «شاخص تناسب با شرایط اعلام‌شده» معرفی می‌شوند و هرگز به عنوان شانس ویزا یا احتمال پذیرش ادعا نمی‌شوند.

### ت) پرونده مقصد (Destination Dossier) و چک‌لیست حقوقی مدارک
- تفکیک قطعی **ترجمه رسمی** از **تأییدات دادگستری/امور خارجه و آپوستیل کنسولی**.
- تفکیک هزینه‌ها: تمکن مصوب دولتی + شهریه سال اول + بلیت و ودیعه استقرار + همراهان.
- استناد به آخرین بخشنامه‌های دولتی مصوب (مانند تمکن ۲۳٬۴۴۸ دلاری کانادا از ۱ سپتامبر ۲۰۲۶، حساب مسدود ۱۱٬۹۰۴ یورویی آلمان، تغییرات زبان B2 نیروی کار بریتانیا در ۸ ژانویه ۲۰۲۶ و الزامات ساب‌کلاس ۵۰۰ استرالیا در ۲ اکتبر ۲۰۲۶).
- تعیین زنجیره وابستگی‌ها (Job Offer, ECA, Sponsor, University LoA, Biometrics).

### ث) رزومه‌یار و بهینه‌ساز ATS
- ممیزی فنی چیدمان، خوانایی ATS و هشدارهای منطقه‌ای (توصیه به حذف عکس و اطلاعات شخصی حساس برای مقاصد آمریکای شمالی/بریتانیا).
- پیشنهاد بازنویسی بولت‌پوینت‌های سابقه کار بر پایه الگوی:  
  `[فعل کنشی استاندارد] + [دامنه تخصصی و ابزار] + [نتیجه قابل سنجش و خروجی کسب‌وکار]`  
  تمامی عبارات پیشنهادی با برچسب شفاف **«پیشنهاد ویرایشی، نیازمند تأیید کاربر»** ارائه شده و هیچ عدد، شرکت یا مهارت ساختگی تولید نمی‌شود.
- تولید پیش‌نویس سفارشی کاورلتر (Cover Letter) و پیام ارتباط با استخدام‌کننده در لینکدین.
- ویزارد ساخت رزومه پایه از اطلاعات فرم ارزیابی.

### ج) درگاه فرصت‌های رسمی، متدولوژی STAR و پیشگیری از کلاهبرداری
- پرتال‌های کاریابی مستقیم دولتی با فیلتر اسپانسرشیپ ویزا (Canada Job Bank, BA Jobsuche, Workforce Australia, GOV.UK).
- بانک بورسیه‌ها و پوزیشن‌های دکترای اروپایی (DAAD, Erasmus Mundus, Campus France Eiffel, MEXT, GKS, EURAXESS, AcademicTransfer).
- راهنمای مصاحبه مبتنی بر چارچوب ۴ مرحله‌ای STAR با مثال‌های واقعی و خطاهای متداول.
- هشدارهای پیشگیرانه درباره کلاهبرداری‌های جاب‌آفر پولی، مقاله‌فروشی در ژورنال‌های نامعتبر، ویزای تضمینی و پیامدهای درج سابقه تقلب (Misrepresentation).

### چ) حریم خصوصی بر پایه طراحی (Privacy by Design) و منشور ماده ۲۳
- تمامی داده‌ها منحصراً در مرورگر ذخیره می‌شوند.
- امکان دانلود فایل پشتیبان پروفایل به فرمت JSON و بازگردانی مجدد.
- دکمه پاک‌سازی قطعی و فوری کلیه اطلاعات ثبت‌شده با یک کلیک.
- متن کامل سلب مسئولیت حقوقی مبنی بر اینکه کوچیفای وکیل دادگستری، مشاور رسمی یا تضمین‌کننده صدور ویزا نیست.

## ۲. پشته فناوری (Technology Stack)

- **هسته فرانت‌اند:** React 19 + TypeScript + Vite 6
- **استایل‌دهی:** Tailwind CSS 4 با پیکربندی کامل راست‌به‌چپ (RTL) و تایپوگرافی فارسی
- **آیکون‌ها:** Lucide React
- **انیمیشن‌ها:** Motion
- **پایداری محلی:** ۱۰۰٪ منطق تطبیق، محاسبه تمکن و تحلیل رزومه به صورت Local و Client-Side بدون نیاز به سرور پولی یا اینترنت
- **بک‌اند اختیاری:** Node.js + Express (برای میزبانی استاتیک و در صورت نیاز توسعه API)
- **تست خودکار:** Node.js Test Runner + tsx

## ۴. نحوه اجرا و استقرار محلی

### پیش‌نیازها
- Node.js نگارش ۱۸ یا بالاتر
- npm یا pnpm

### گام‌های اجرا

۱. **نصب وابستگی‌ها:**
```bash
npm install
```

۲. **اجرای آزمون‌های پذیرش خودکار:**
```bash
npm test
```
این دستور ۹ آزمون حیاتی سامانه (پالایش شروط مسدودکننده، تضمین ۳ کشور متمایز، جداسازی هزینه‌ها، عدم پیش‌بینی احتمال ویزا و...) را با Node.js Test Runner اجرا می‌کند.

۳. **بررسی انواع و تایپ‌ها:**
```bash
npm run lint
```

۴. **ساخت نسخه پروداکشن (Build):**
```bash
npm run build
```

۵. **اجرای محلی در محیط توسعه یا پروداکشن:**
```bash
# اجرای نسخه پروداکشن ساخته‌شده:
npm start

# یا اجرای سرور توسعه با Vite:
npm run dev
```

سامانه به طور پیش‌فرض روی نشانی زیر در دسترس خواهد بود:
```text
http://localhost:3001
```

## ۵. نحوه به‌روزرسانی داده‌ها و قوانین جدید بدون تغییر فرانت‌اند

تمامی اطلاعات مهاجرتی در قالب آرایه‌های تایپ‌شده و ماژولار در پوشه `src/data/` سازمان‌دهی شده‌اند. جهت به‌روزرسانی مقررات:

1. **تغییر مبالغ تمکن یا تاریخ‌های لازم‌الاجرا:**
   فایل `src/data/routesData.ts` را باز کرده و در آبجکت `proofOfFunds` مسیر مربوطه، مقادیر `livingAmountSingle`، `effectiveFrom` و `sourceId` را ویرایش کنید.
2. **افزودن منبع رسمی جدید:**
   شناسه منبع را در `src/data/migrationSources.ts` با فیلدهای `canonicalUrl`، `effectiveFrom` و `checkedAt` اضافه نمایید.
3. **به‌روزرسانی مشاغل دارای کمبود:**
   فایل `src/data/occupationsData.ts` شامل کدهای استاندارد شغلی و نیازمندی‌های لایسنس است که می‌توانید مشاغل جدید را به آن بیافزایید.
4. **گسترش کاتالوگ ۳۰ کشور:**
   در صورت بازبینی کامل یک کشور جدید، فیلد `dataCompletenessPercent` و `confidenceLevel` را در `src/data/countryCatalog.ts` اصلاح کنید.

## ۷. مواردی که نیازمند بازبینی وکیل یا استعلام موردی سفارت هستند

با توجه به اصل شفافیت و تعهد اخلاقی سامانه:
1. **آیین‌نامه‌های اجرایی ویزامتریک در تهران:** زمان‌بندی نوبت‌دهی مصاحبه در کارگزاری‌های داخلی (نظیر ویزامتریک آلمان یا VFS ایتالیا و کانادا) به صورت هفتگی متغیر است و همواره باید از وب‌سایت همان کارگزار استعلام شود.
2. **ارزیابی تطبیقی مدارک دانشگاه‌های غیردولتی/آزاد در پایگاه Anabin:** در حالی که مدارک دانشگاه‌های دولتی اغلب برچسب H+ دارند، برخی گرایش‌های خاص نیازمند استعلام انفرادی از مرجع ZAB هستند.
3. **امکان الحاق هم‌زمان همراهان در دوره‌های کالج زبان یا مقاطع پایین‌تر:** به دلیل سخت‌گیری‌های اخیر در کشورهای کانادا، بریتانیا و استرالیا، صدور ویزای کار همراه (SOWP) برای مقاطع کارشناسی در برخی کشورها محدود شده است که در کارت هر مقصد با علامت هشدار نشان داده شده است.
